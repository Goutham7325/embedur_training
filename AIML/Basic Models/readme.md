## Question 1: Customer Sales Analysis

### Objective
Analyze customer sales data using Python and Pandas.

### Tasks
- Load a CSV file containing sales transactions using Pandas.
- Clean missing values.
- Compute total revenue by product category.
- Identify the top 10 customers based on revenue.
- Visualize monthly sales using Matplotlib.

### Expected Deliverables
- Python source code
- Cleaned dataset (CSV)
- Summary statistics
- Two plots:
  - Revenue by product category
  - Monthly sales trend

# General Submission Guidelines

## Programming Environment
- Python 3.11+

## Preferred Libraries
- pandas
- numpy
- matplotlib
- scikit-learn
- TensorFlow or PyTorch (only for advanced deep-learning questions)

## Submission Contents
- Source code
- Report
- Screenshots and plots
- README containing:
  - Project description
  - Installation instructions
  - Dependencies
  - Steps to run the project
  - Expected outputs
