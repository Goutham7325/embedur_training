## Basic Models
A collection of introductory machine learning and deep learning projects covering data analysis, classical ML algorithms, and image classification. The notebooks demonstrate the complete workflow from data preprocessing and exploratory analysis to model training and evaluation using Python, Scikit-learn, TensorFlow, and PyTorch.

**Topics Covered:**
- Customer Sales Analysis
- Iris Classification
- MNIST Digit Classification
- Titanic Survival Prediction
- Spam Email Classification
- Image Classification
- Manufacturing Defect Detection
- Face Mask Detection

## OpenCV
A set of computer vision exercises implemented using OpenCV. These notebooks cover essential image processing operations, feature detection, filtering, transformations, camera calibration, and lens distortion correction, providing hands-on experience with fundamental computer vision techniques.

**Topics Covered:**
- Image Processing
- Filtering and Transformations
- Feature Detection
- Camera Calibration
- Lens Undistortion
- Image Capture and Analysis

## Tensor Quantization
A collection of notebooks demonstrating the fundamentals of neural network quantization and model deployment. The exercises explore different quantization techniques, analyze quantization error, compare quantization strategies, and implement an end-to-end conversion pipeline from PyTorch to a fully INT8 TensorFlow Lite model.

**Topics Covered:**
- Basic Affine Quantization
- Scale and Zero Point Calculation
- Symmetric vs Asymmetric Quantization
- Bit-width Analysis (INT8/INT6/INT4)
- Per-Tensor vs Per-Channel Quantization
- PyTorch → ONNX → TensorFlow → INT8 TFLite Conversion
