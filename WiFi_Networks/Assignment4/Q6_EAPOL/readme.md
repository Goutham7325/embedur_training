# EAPOL 4-Way Handshake (WPA2/WPA3) – Steps and Key Derivation

## Overview

The **EAPOL (Extensible Authentication Protocol over LAN) 4-way handshake** is used in WPA2/WPA3 to securely establish encryption keys between:

- **STA (Client / Supplicant)**
- **AP (Authenticator)**

It occurs **after association** and ensures:
- Mutual proof of possession of a shared secret (**PMK**)
- Fresh session key generation
- Secure installation of encryption keys

---

## Key Terms

- **PMK (Pairwise Master Key)**  
  - Derived from:
    - WPA2-Personal: Passphrase (PSK)
    - WPA2-Enterprise: EAP authentication  
  - Known to both STA and AP

- **ANonce**: Random number generated by AP  
- **SNonce**: Random number generated by STA  

- **PTK (Pairwise Transient Key)**  
  - Derived from PMK, ANonce, SNonce, and MAC addresses  
  - Split into multiple keys (explained later)

---

## 4-Way Handshake Steps

### Step 1: AP → STA (Message 1)

- AP sends:
  - **ANonce**
- Purpose:
  - Initiates handshake
  - STA now has all inputs (except SNonce) to derive PTK

---

### Step 2: STA → AP (Message 2)

- STA generates:
  - **SNonce**
- STA computes:
  - **PTK = PRF(PMK, ANonce, SNonce, MAC_AP, MAC_STA)**

- STA sends:
  - SNonce
  - **MIC (Message Integrity Code)** using PTK

- Purpose:
  - Proves STA knows PMK
  - Shares SNonce for AP to compute PTK

---

### Step 3: AP → STA (Message 3)

- AP computes PTK using:
  - PMK, ANonce, SNonce, MAC addresses

- AP sends:
  - **GTK (Group Temporal Key)** (encrypted)
  - MIC

- Purpose:
  - Installs encryption keys
  - Provides group key for broadcast/multicast traffic

---

### Step 4: STA → AP (Message 4)

- STA installs:
  - PTK
  - GTK

- STA sends:
  - ACK with MIC

- Purpose:
  - Confirms successful key installation
  - Handshake completion

## PTK Structure and Derived Keys

The **Pairwise Transient Key (PTK)** is divided into multiple subkeys:

### 1. KCK (Key Confirmation Key)
- Used to compute and verify **MIC**
- Ensures integrity of EAPOL messages

---

### 2. KEK (Key Encryption Key)
- Used to **encrypt GTK**
- Protects key distribution

---

### 3. TK (Temporal Key)
- Used for **data encryption**
- Example:
  - WPA2: AES-CCMP
  - WPA3: AES-GCMP

---

### 4. MIC Keys (sometimes grouped with KCK)
- Used for message authentication in some implementations

---

## Group Key (GTK)

- Generated by AP
- Used for:
  - **Broadcast traffic**
  - **Multicast traffic**
- Shared among all clients in the network
- Periodically updated for security
