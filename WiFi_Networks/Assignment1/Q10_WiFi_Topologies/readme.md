## Wi-Fi Topologies and Their Use Cases

Wi-Fi networks can be organized in different **topologies** depending on how devices and access points are arranged and communicate.

---

### 1. Infrastructure Mode (BSS)

**Description:**
- Devices connect through a **single Access Point (AP)**
- Centralized communication (client → AP → client)

**Use Cases:**
- Home networks  
- Small offices  
- Cafes and small shops  

---

### 2. Extended Infrastructure Mode (ESS)

**Description:**
- Multiple APs interconnected via a **distribution system (wired LAN)**
- Same SSID across APs enables **roaming**

**Use Cases:**
- College campuses  
- Corporate offices  
- Airports and malls  

---

### 3. Ad-Hoc Mode (IBSS – Independent BSS)

**Description:**
- Devices communicate **directly with each other**
- No access point required

**Use Cases:**
- Temporary file sharing  
- Small peer-to-peer networks  
- Emergency communication setups  

---

### 4. Mesh Topology

**Description:**
- Multiple APs (nodes) connected **wirelessly to each other**
- Dynamic routing between nodes
- Self-healing network

**Use Cases:**
- Smart homes (mesh routers)  
- Large buildings without Ethernet wiring  
- Outdoor/city-wide Wi-Fi networks  

---

### 5. Point-to-Point (P2P) Topology

**Description:**
- Direct wireless link between **two locations**
- Uses directional antennas

**Use Cases:**
- Connecting two buildings  
- ISP backhaul links  
- CCTV network links between sites  

---

### 6. Point-to-Multipoint (P2MP)

**Description:**
- One central AP connects to **multiple remote nodes**
- Typically used in outdoor wireless deployments

**Use Cases:**
- Wireless ISPs (WISPs)  
- Rural internet distribution  
- Campus-wide connectivity  

---

### 7. Repeater / Range Extender Topology

**Description:**
- Extends an existing Wi-Fi network by **retransmitting signals**
- No wired backhaul required

**Use Cases:**
- Eliminating dead zones in homes  
- Extending coverage to upper floors  
- Small office expansions  

---

### 8. Wireless Distribution System (WDS)

**Description:**
- APs connected wirelessly to form a network
- Combines features of **bridge and repeater**

**Use Cases:**
- Linking APs without cables  
- Expanding networks in areas where wiring is difficult  

---

## Summary Table

| Topology            | Key Feature                     | Use Case Example              |
|---------------------|--------------------------------|-------------------------------|
| Infrastructure (BSS)| Single AP                      | Home Wi-Fi                    |
| ESS                 | Multiple APs, roaming          | Campus network                |
| Ad-Hoc (IBSS)       | No AP, direct communication    | Temporary file sharing        |
| Mesh                | Self-healing multi-node        | Smart homes, city Wi-Fi       |
| Point-to-Point      | One-to-one link                | Building connectivity         |
| Point-to-Multipoint | One-to-many link               | Rural ISP                     |
| Repeater            | Signal extension               | Dead zone coverage            |
| WDS                 | Wireless AP interconnection    | Cable-less expansion          |

---

## Conclusion
Different Wi-Fi topologies are chosen based on **coverage, scalability, cost, and infrastructure availability**.  
- **Simple setups** use BSS  
- **Large networks** use ESS or Mesh  
- **Special links** use P2P or P2MP
