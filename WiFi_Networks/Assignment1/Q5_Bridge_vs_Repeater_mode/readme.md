## Difference Between Bridge Mode and Repeater Mode (Wi-Fi)

### 1. Bridge Mode

**Definition:**  
Bridge mode connects **two separate networks (usually wired LANs)** using a wireless link. It acts like a **wireless cable replacement** between networks.

**Key Points:**
- Connects **two LAN segments**
- Typically uses **point-to-point or point-to-multipoint** links
- Does **not extend Wi-Fi coverage for clients directly**
- Devices connect via **Ethernet to the bridge**, not Wi-Fi (in most cases)

**Use Case Example:**  
Connecting two buildings’ networks wirelessly without laying cables.

---

### 2. Repeater Mode

**Definition:**  
Repeater mode **extends the coverage of an existing Wi-Fi network** by receiving and retransmitting the signal.

**Key Points:**
- Connects to an existing Wi-Fi network **wirelessly**
- Rebroadcasts the same SSID (or a similar one)
- **Extends coverage area** for wireless clients
- Clients connect directly to the repeater via Wi-Fi

**Use Case Example:**  
Improving Wi-Fi signal strength in areas with weak coverage (e.g., another room or floor).

---

## Key Differences

| Feature              | Bridge Mode                              | Repeater Mode                          |
|----------------------|------------------------------------------|----------------------------------------|
| Purpose              | Connect two networks                     | Extend Wi-Fi coverage                  |
| Connection Type      | Typically wired ↔ wireless ↔ wired       | Wireless ↔ wireless                    |
| Client Access        | Usually via Ethernet                     | Wireless clients connect directly      |
| Coverage Extension   | No                                       | Yes                                    |
| Performance Impact   | Minimal loss                            | Reduced throughput (due to retransmit) |
| Use Case             | Building-to-building link                | Home/office signal extension           |

---

## Summary
- **Bridge Mode:** Connects networks (acts like a wireless link between LANs)  
- **Repeater Mode:** Extends an existing Wi-Fi network’s range  

Both are useful but serve **different networking purposes**.
