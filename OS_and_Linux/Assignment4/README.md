# Bash Script – Parameter Extraction from Input File

## Problem Statement
Write a Bash script that:
- Takes an input file (`input.txt`) as input
- Reads the file **line by line**
- Extracts the following parameters:
  - `frame.time`
  - `wlan.fc.type`
  - `wlan.fc.subtype`
- Generates an output file named `output.txt` in the required format

---

## Expected Parameters
- `"frame.time"`
- `"wlan.fc.type"`
- `"wlan.fc.subtype"`

---

## Sample Output Format (`output.txt`)
```text
"frame.time": "Nov 14, 2024 11:44:48.219200000 India Standard Time",
"wlan.fc.type": "1",
"wlan.fc.subtype": "9"

"frame.time": "Nov 14, 2024 11:44:48.219208000 India Standard Time",
"wlan.fc.type": "0",
"wlan.fc.subtype": "1"

```
