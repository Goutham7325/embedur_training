# Ethernet Frame Capture and Analysis using Wireshark (GNS3)

## Objective
The objective of this experiment is to capture and analyze Ethernet frames using Wireshark. The structure of the frame is inspected, including the destination MAC address, source MAC address, EtherType, payload, and Frame Check Sequence (FCS). Network traffic is generated using ping in a simulated network environment.

---

## Network Setup

A small LAN was simulated using **GNS3** with two virtual PCs connected through a switch.

### Topology

```
        Switch
        /   \
      PC1   PC2
192.168.1.1 192.168.1.2
```

- **PC1 IP Address:** 192.168.1.1  
- **PC2 IP Address:** 192.168.1.2  
- **Subnet Mask:** 255.255.255.0  

Both hosts belong to the same local network.

## Traffic Generation

Network traffic was generated using the `ping` command from PC1 to PC2.

Command executed:

```bash
ping 192.168.1.2
```

Example output:

```
84 bytes from 192.168.1.2 icmp_seq=1 ttl=64 time=0.143 ms
84 bytes from 192.168.1.2 icmp_seq=2 ttl=64 time=0.716 ms
84 bytes from 192.168.1.2 icmp_seq=3 ttl=64 time=0.127 ms
```

This confirms successful communication between the two hosts.

---

## Packet Capture using Wireshark

Steps followed:

1. Start the network topology in **GNS3**.
2. Right-click the link between PC1 and the switch.
3. Select **Start Capture**.
4. Wireshark opens automatically.
5. Run the `ping` command between the hosts.
6. Observe captured packets in Wireshark.

Captured packets include:

- ICMP Echo Request
- ICMP Echo Reply

---

## Ethernet Frame Analysis

The captured packets show the **Ethernet II frame format**.

### Ethernet Frame Structure

| Field | Description |
|------|------|
| Destination MAC Address | MAC address of the receiving device |
| Source MAC Address | MAC address of the sending device |
| EtherType | Identifies the encapsulated protocol |
| Payload | Actual transmitted data |
| Frame Check Sequence (FCS) | Error detection field |

---

## Example Frame from Wireshark

Example captured frame:

```
Ethernet II
Destination: 00:50:79:66:68:01
Source:      00:50:79:66:68:00
Type:        IPv4 (0x0800)
```

Explanation:

- **Destination MAC:** MAC address of PC2  
- **Source MAC:** MAC address of PC1  
- **EtherType:** Indicates IPv4 protocol  
- **Payload:** Contains the ICMP packet generated by ping
